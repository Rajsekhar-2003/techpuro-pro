The technology industry offers many career paths, and beginners often get stuck on one question: *what should I learn first?*

This guide gives you 14 clear roadmaps. Each one explains what the job involves, what to learn and in what order, which projects to build, and which job titles to look for. You do not need to follow all of them. Read the comparison, choose one, and start.

## Roadmaps at a glance

This table is an editorial guide to help you compare paths. Difficulty and maths needs vary by role and employer.

| Roadmap | Main language | You will mostly... | Maths needed |
|---------|---------------|--------------------|--------------|
| Frontend | JavaScript / TypeScript | Build website interfaces | Low |
| Backend | Python, JavaScript, Java | Build servers and APIs | Low |
| Full-stack | JavaScript / TypeScript | Build complete web apps | Low |
| Mobile | Kotlin, Swift, Dart | Build phone apps | Low |
| AI developer | Python | Build apps using AI models | Low to medium |
| Machine learning | Python | Train models on data | Medium to high |
| Deep learning | Python | Build neural networks | High |
| Generative AI | Python | Build chatbots and content tools | Medium |
| Data scientist | Python, SQL | Find patterns and predict | Medium to high |
| Data analyst | SQL, Excel, Python | Turn data into reports | Low to medium |
| Cybersecurity | Python, Bash | Protect systems | Low |
| DevOps | Bash, Python | Automate deployment | Low |
| Blockchain | Solidity, JavaScript | Build smart contracts | Medium |
| Game developer | C#, C++ | Build games | Medium to high |

## 1. Frontend Developer Roadmap

A frontend developer builds what users see and click on a website: layouts, menus, forms and animations. The work mixes design sense with code.

**Learn in this order**

1. **HTML, CSS and JavaScript.** These are the base of every website. Learn page structure, layout, responsive design and how to make pages interactive.
2. **A CSS framework.** Tailwind CSS and Bootstrap save time. Tailwind is a popular default if you want design control.
3. **A frontend framework.** React is the most widely used, and Next.js builds on it. Vue, Angular, Svelte and Astro are good alternatives.
4. **TypeScript.** It adds types to JavaScript and catches mistakes early.
5. **Tools.** Git, GitHub, npm, Vite and your browser's developer tools.
6. **Quality.** Testing, accessibility, page speed (Core Web Vitals) and basic SEO.
7. **Deployment.** Publish on Cloudflare Pages, Vercel, Netlify or GitHub Pages.

**Starter projects:** a portfolio site, a responsive landing page, a weather app, an admin dashboard, an online shop front end.

**Typical stack:** HTML, CSS, TypeScript, Tailwind CSS, React or Next.js, Git, Vitest or Playwright for tests.

**Job titles:** Frontend Developer, React Developer, UI Developer, Web Application Developer.

For the full web path, see our [web developer roadmap](/guides/web-developer-roadmap/).

## 2. Backend Developer Roadmap

A backend developer builds the part users never see: servers, databases, logins and APIs. If the frontend is the shop window, the backend is the stockroom and the cash register.

**Learn in this order**

1. **One main language.** Python, JavaScript/TypeScript, Java, PHP, C# or Go. Pick one and learn it well.
2. **One framework.** FastAPI, Django or Flask for Python; Express or NestJS for JavaScript; Spring Boot for Java; Laravel for PHP; ASP.NET Core for C#; Gin or Fiber for Go.
3. **APIs.** REST, HTTP methods, status codes, JSON, validation and documentation.
4. **Databases.** Start with SQL and PostgreSQL. Add Redis for caching later.
5. **Authentication and security.** Sessions, JWT, OAuth, password hashing, CORS, rate limiting and protection against SQL injection.
6. **Architecture.** Middleware, background jobs, caching, indexes and the basics of load balancing.
7. **Deployment.** Linux, SSH, Nginx, Docker, and a VPS or cloud host. See how to [deploy a website](/guides/how-to-deploy-a-website/).

**Starter projects:** a login API, a blog backend, an online shop API, a file-sharing app, a real-time chat backend.

**Typical stack:** Python, FastAPI, PostgreSQL, Redis, Cloudflare R2 or AWS S3, Docker.

**Job titles:** Backend Developer, API Developer, Python Developer, Node.js Developer, Software Engineer.

Compare options in our guide to the [top backend programming languages](/programming/top-10-backend-programming-languages/).

## 3. Full-Stack Developer Roadmap

A full-stack developer works on both the frontend and the backend, so they can build a complete product alone or in a small team.

**Learn in this order**

1. **Frontend basics:** HTML, CSS, JavaScript and TypeScript.
2. **A frontend framework:** React with Next.js is a common pairing.
3. **One backend stack:** Node.js with Express or NestJS, or Python with FastAPI or Django.
4. **A database:** PostgreSQL first, then Redis or MongoDB if needed.
5. **APIs and authentication:** REST, logins, permissions and, for real-time features, WebSockets.
6. **Tools:** Git, GitHub, Docker and Postman.
7. **Deployment:** Vercel, Cloudflare, Railway, Render, a VPS or AWS.

**Starter projects:** a full-stack blog, an online shop, a file-sharing site, a chat app, a small SaaS product.

**Typical stack:** TypeScript, React or Next.js, Tailwind CSS, Node.js or NestJS, PostgreSQL, Docker.

**Job titles:** Full-Stack Developer, Software Engineer, SaaS Developer, Freelance Web Developer.

## 4. Mobile App Developer Roadmap

A mobile developer builds apps for Android and iPhone. You can build for each platform separately or use one codebase for both.

**Learn in this order**

1. **Programming basics** and how apps are structured.
2. **Choose a path.** Kotlin for native Android, Swift for native iOS, or Flutter (Dart) and React Native for both platforms from one codebase.
3. **User interface.** Screens, navigation, lists, forms and responsive layouts for different phone sizes.
4. **Data.** Calling APIs, storing data on the device and syncing with a server.
5. **Device features.** Camera, location, notifications and permissions.
6. **Quality.** Testing, performance and battery use.
7. **Publishing.** Learn the Google Play and Apple App Store release processes.

**Starter projects:** a to-do app, an expense tracker, a notes app with cloud sync, a weather app.

**Typical stack:** Flutter with Dart, or Kotlin (Android) and Swift (iOS), plus a backend API such as FastAPI or Node.js.

**Job titles:** Mobile App Developer, Android Developer, iOS Developer, Flutter Developer.

## 5. AI Developer Roadmap

An AI developer builds software that *uses* existing AI models, for example a support chatbot, a document assistant or smart search. You mostly connect models to real products rather than train them from scratch.

**Learn in this order**

1. **Python and programming basics:** data structures, functions and object-oriented code.
2. **Basic maths:** a gentle grounding in statistics and probability is enough to start.
3. **Data handling:** NumPy, Pandas, CSV and JSON.
4. **AI fundamentals:** what machine learning, neural networks, language and vision models do.
5. **Model APIs and prompting:** calling hosted models, writing clear prompts, structured outputs and tool use.
6. **Embeddings, vector databases and RAG.** Retrieval-Augmented Generation lets a model answer from your own documents.
7. **Backend integration:** wrap it all in FastAPI or Flask, with logins and a database.

**Starter projects:** a chatbot, a document Q&A assistant, an AI-powered search, a summariser, a customer support tool.

**Typical stack:** Python, FastAPI, model APIs, Pandas, a vector database such as Qdrant, PostgreSQL, Docker.

**Job titles:** AI Developer, AI Application Engineer, LLM Application Developer, AI Integration Developer.

## 6. Machine Learning Engineer Roadmap

A machine learning engineer trains models that learn patterns from data and make predictions, such as spotting spam or predicting house prices. Then they put those models into production.

**Learn in this order**

1. **Python** and clean coding habits.
2. **Maths:** linear algebra, probability, statistics and basic calculus.
3. **Data processing:** NumPy, Pandas, Matplotlib, cleaning data and creating useful features.
4. **Core concepts:** supervised and unsupervised learning, classification, regression, clustering and how to evaluate a model.
5. **Libraries:** scikit-learn first, then XGBoost, LightGBM or CatBoost.
6. **Improving models:** cross-validation, hyperparameter tuning, ensembles and explaining results.
7. **Deployment (MLOps):** serve models with FastAPI and Docker, track them with MLflow and monitor them after launch.

**Starter projects:** house price prediction, customer churn, spam detection, fraud detection, a recommendation system.

**Typical stack:** Python, Pandas, scikit-learn, XGBoost, FastAPI, MLflow, Docker, PostgreSQL.

**Job titles:** Machine Learning Engineer, Applied ML Engineer, MLOps Engineer, ML Developer.

## 7. Deep Learning and Neural Network Engineer Roadmap

Deep learning is a branch of machine learning that uses neural networks with many layers. It powers image recognition, speech tools and modern language models. This roadmap covers both deep learning and neural network design, since the two are closely linked.

**Learn in this order**

1. **Python, NumPy and Pandas.**
2. **Maths:** linear algebra, calculus, probability and optimisation. This path needs more maths than most others.
3. **Machine learning basics:** regression, classification and model evaluation.
4. **How neural networks work:** neurons, layers, activation and loss functions, backpropagation and gradient descent.
5. **A framework:** PyTorch is widely used in research and industry; TensorFlow and Keras are also common.
6. **Architectures:** CNNs for images, RNNs and LSTMs for sequences, Transformers for language, and autoencoders.
7. **Performance:** GPU computing, batching, model compression and quantisation.

**Starter projects:** build a small neural network from scratch, image classification, handwriting recognition, object detection, speech recognition.

**Typical stack:** Python, PyTorch, NumPy, CUDA-capable GPU (or a cloud GPU), Jupyter, FastAPI, Docker.

**Job titles:** Deep Learning Engineer, Computer Vision Engineer, Applied AI Engineer, AI Research Engineer.

## 8. Generative AI Engineer Roadmap

A generative AI engineer builds tools that create or transform text, images, audio and more. It overlaps with the AI developer path but goes deeper into how language models work and how to adapt them.

**Learn in this order**

1. **Python and APIs**, with some JavaScript or TypeScript.
2. **AI foundations:** machine learning, deep learning and natural language processing.
3. **How large language models work:** tokens, embeddings, attention, context windows and inference.
4. **Tools:** Hugging Face, PyTorch and hosted model APIs.
5. **Prompt engineering:** clear instructions, structured outputs, tool calling and testing your results.
6. **RAG:** document processing, chunking, embeddings, vector search and measuring answer quality.
7. **Advanced topics:** fine-tuning, LoRA, quantisation, agent workflows and multimodal models.
8. **Production:** FastAPI, PostgreSQL, Redis, vector databases and Docker.

**Starter projects:** a chatbot, a PDF question-answering system, a research assistant, a document summariser, a multimodal app.

**Typical stack:** Python, FastAPI, model APIs or Hugging Face, PyTorch, Sentence Transformers, Qdrant or Pinecone, PostgreSQL.

**Job titles:** Generative AI Engineer, LLM Engineer, AI Agent Developer, Applied AI Engineer.

## 9. Data Scientist Roadmap

A data scientist uses programming, statistics and machine learning to answer questions and make predictions from complex data.

**Learn in this order**

1. **Python and SQL.** Basic R is a useful extra.
2. **Statistics and maths:** descriptive statistics, probability, hypothesis testing and regression.
3. **Data analysis:** NumPy, Pandas, cleaning data and exploratory data analysis.
4. **Visualisation:** Matplotlib, Seaborn, Plotly, and BI tools like Power BI or Tableau.
5. **Machine learning:** scikit-learn, with regression, classification and clustering.
6. **Advanced skills:** feature engineering, experiment design, statistical modelling and time-series analysis.
7. **Tools:** Jupyter Notebook, Git, MLflow and a cloud platform.

**Starter projects:** sales prediction, customer segmentation, churn analysis, a recommendation system.

**Typical stack:** Python, SQL, Pandas, scikit-learn, Seaborn, Jupyter, PostgreSQL.

**Job titles:** Data Scientist, Applied Data Scientist, Research Analyst, Predictive Analytics Specialist.

## 10. Data Analyst Roadmap

A data analyst collects and cleans data, then turns it into charts and reports that help a business decide what to do. It is one of the most approachable data careers.

**Learn in this order**

1. **Excel:** formulas, lookups, pivot tables, charts and cleaning data.
2. **SQL:** SELECT, WHERE, GROUP BY, JOIN, subqueries and window functions.
3. **Python basics:** Pandas and NumPy for larger or messier data.
4. **Dashboards:** Power BI or Tableau, plus Matplotlib and Seaborn for charts.
5. **Statistics:** averages, spread, correlation and simple hypothesis tests.
6. **Business thinking:** KPIs, sales, finance and customer analysis, and writing clear reports.

**Starter projects:** a sales dashboard, an expense dashboard, a customer behaviour analysis, a business performance report.

**Typical stack:** Excel, SQL, Python with Pandas, Power BI or Tableau, PostgreSQL.

**Job titles:** Data Analyst, Business Analyst, BI Analyst, Reporting Analyst, Product Analyst.

## 11. Cybersecurity Roadmap

A cybersecurity professional protects systems, networks and data from attacks. Roles range from defending and monitoring to testing security on purpose.

**Learn in this order**

1. **Computer basics:** operating systems (especially Linux and Windows) and how computers work.
2. **Networking:** TCP/IP, DNS, HTTP/HTTPS, firewalls, VPNs and common protocols.
3. **Scripting:** Python, Bash and PowerShell to automate tasks.
4. **Security basics:** the CIA triad (confidentiality, integrity, availability), encryption, authentication, access control and vulnerability management.
5. **Tools:** Wireshark, Nmap, Burp Suite, OWASP ZAP and SIEM platforms. Metasploit is used by authorised testers.
6. **A specialisation:** network security, application security, cloud security, SOC analysis, penetration testing, digital forensics or incident response.
7. **Standards:** the OWASP Top 10, the NIST Cybersecurity Framework, ISO 27001 basics and secure coding.

**Starter projects:** a home network monitoring lab, a log analysis dashboard, a vulnerability scan in a lab you own, a secure login system, an incident write-up.

**Typical stack:** Linux, Python, Bash, Wireshark, Nmap, Burp Suite, Splunk or Elastic.

**Job titles:** Cybersecurity Analyst, SOC Analyst, Security Engineer, Penetration Tester, Cloud Security Engineer.

> Only test security on systems you own or have written permission to test.

## 12. DevOps Engineer Roadmap

A DevOps engineer helps teams ship software faster and more safely by automating building, testing, deploying and monitoring.

**Learn in this order**

1. **Linux:** commands, permissions, processes and shell scripting.
2. **Scripting:** Bash, Python and YAML. Basic Go is a plus.
3. **Networking:** TCP/IP, DNS, HTTP, SSH, load balancing and reverse proxies.
4. **Git and GitHub:** branching, pull requests and team workflows.
5. **CI/CD:** GitHub Actions, GitLab CI or Jenkins to test and deploy automatically.
6. **Containers:** Docker and Docker Compose.
7. **Cloud:** AWS, Azure or Google Cloud (pick one first).
8. **Infrastructure as code:** Terraform and Ansible.
9. **Orchestration:** Kubernetes and Helm. See [Docker vs Kubernetes](/software/docker-vs-kubernetes/) to understand where each fits.
10. **Monitoring:** Prometheus, Grafana, the ELK stack and OpenTelemetry.

**Starter projects:** an automated deployment, a Dockerised web app, a CI/CD pipeline, a small Kubernetes deployment.

**Typical stack:** Linux, Bash, Git, Docker, GitHub Actions, one cloud, Terraform, Kubernetes, Prometheus and Grafana.

**Job titles:** DevOps Engineer, Cloud Engineer, Site Reliability Engineer (SRE), Platform Engineer.

## 13. Blockchain Developer Roadmap

A blockchain developer builds smart contracts, which are programs that run on a blockchain, and decentralised apps. Security matters a great deal because deployed contracts are hard to change.

**Learn in this order**

1. **Programming basics:** JavaScript, TypeScript or Python.
2. **Blockchain fundamentals:** distributed ledgers, hashing, public and private keys, digital signatures, consensus and transactions.
3. **A platform:** Ethereum is the most common starting point. Solana, Polygon and Hyperledger Fabric are other options.
4. **Smart contracts:** Solidity, deployment, events and gas costs.
5. **Tools:** Remix, Hardhat or Foundry, and Ethers.js or Web3.js.
6. **Frontend connection:** React or Next.js with wallet integration.
7. **Security:** testing, access control, reentrancy bugs and contract auditing basics.

**Starter projects:** a simple token, a voting app, an NFT marketplace, a small decentralised app.

**Typical stack:** Solidity, Hardhat or Foundry, Ethers.js, React, Node.js, IPFS.

**Job titles:** Blockchain Developer, Smart Contract Developer, Web3 Developer, Blockchain Security Engineer.

## 14. Game Developer Roadmap

A game developer builds games for PCs, phones and consoles. The work combines programming with maths, graphics, physics and design.

**Learn in this order**

1. **One language:** C# (Unity or Godot), C++ (Unreal Engine) or GDScript (Godot).
2. **Maths for games:** vectors, matrices, geometry, trigonometry and basic physics.
3. **A game engine:** Unity, Unreal Engine or Godot. Godot is free and beginner-friendly, Unity is widely used for mobile and indie games, and Unreal is known for high-end 3D.
4. **Core ideas:** game loops, objects, collisions, animation, input, scenes and audio.
5. **Graphics:** 2D and 3D, materials, lighting, shaders and rendering.
6. **Advanced topics:** game AI, multiplayer networking, optimisation and physics.
7. **Tools:** Git, Blender and your engine's editor.

**Starter projects:** a 2D platformer, an endless runner, a puzzle game, a small 3D adventure, a multiplayer prototype.

**Typical stack:** C# with Unity or Godot, or C++ with Unreal, plus Blender and Git.

**Job titles:** Game Developer, Unity Developer, Unreal Engine Developer, Gameplay Programmer, Graphics Programmer.

## How to choose the right career

Ask yourself three questions:

1. **What do I enjoy?** Building visible things (frontend, mobile, games), solving logic problems (backend, DevOps), working with data (analyst, scientist), or protecting systems (security)?
2. **How comfortable am I with maths?** AI research, deep learning and data science need the most. Frontend, backend, DevOps and security need less.
3. **What do I want to build first?** Pick the roadmap whose starter projects excite you.

If you are still undecided, learn HTML, CSS, JavaScript and basic Python for a few weeks. These skills help in almost every path, and you will quickly learn what you like.

## A learning strategy that works for any path

1. Learn the fundamentals before frameworks.
2. Choose one main language.
3. Learn the tools of your chosen path.
4. Learn Git and GitHub early.
5. Build small projects, then bigger ones.
6. Learn testing and debugging.
7. Learn how to deploy what you build.
8. Put your best projects in a portfolio with clear write-ups and live links.
9. Practise interview questions.
10. Apply for internships and entry-level roles.

## Conclusion

You do not need to learn all 14 paths. Choose one, learn the fundamentals, master its main tools and keep building real projects.

The best roadmap is not the one with the most technologies. It is the one that helps you build real skills and finish real projects.
